连接 Yakit

电脑先启动 Yakit MITM，允许局域网连接。手机与电脑连接同一局域网，填写电脑 IP 和 Yakit 监听端口，再点击“保存并启动”。HTTPS MITM 需要受信任的 CA，可在“证书管理”中同步并安装 Yakit MITM 证书。

填写电脑 IP，不是手机 IP 或 0.0.0.0。电脑运行 ipconfig 可查看 IPv4 地址。
